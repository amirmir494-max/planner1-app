# پلنر زندگی — اپلیکیشن اندروید (پروژه‌ی Android Studio)

این یک پروژه‌ی کامل اندروید (Java) است که برنامه‌ی «پلنر زندگی ۲» را داخل یک اپ بومی اجرا می‌کند و چند قابلیت واقعی اندروید به آن اضافه می‌کند:

- **یادآور که واقعاً زنگ می‌زند** (نه فقط یک اعلان ساکت): با صدای بلند و تکرارشونده، لرزش، و یک صفحه‌ی تمام‌صفحه که حتی روی صفحه‌ی قفل هم باز می‌شود — دقیقاً مثل اپ ساعت زنگ‌دار. با دکمه‌ی «توقف» یا «۱۰ دقیقه دیگر» بسته می‌شود؛ اگر کاری نکنی، بعد از ۶۰ ثانیه خودش قطع می‌شود.
- **پایان جلسه‌ی تمرکز** هم به همین شکل زنگ می‌زند.
- کار می‌کند حتی وقتی برنامه بسته است یا گوشی خاموش‌وروشن شده باشد.
- **ذخیره‌ی فایل‌ها** (CSV، پشتیبان JSON، تقویم ICS) مستقیم در پوشه‌ی Downloads؛ فایل ICS بلافاصله در تقویم گوشی باز می‌شود.
- انتخاب فایل برای «بازیابی پشتیبان»، دکمه‌ی برگشت هوشمند، آیکون و بدون نیاز به اینترنت (داده‌ها روی خود گوشی می‌مانند).

## ساخت APK (یک‌بار، حدود ۱۰ دقیقه)

۱. **Android Studio** را از developer.android.com/studio نصب کن (نسخه‌ی Koala یا جدیدتر).
۲. `File ← Open` و پوشه‌ی `LifePlanner` را انتخاب کن. صبر کن Gradle Sync تمام شود (اولین بار اینترنت لازم است؛ اگر پیشنهاد نصب «Android SDK Platform 34» داد، قبول کن).
۳. منوی `Build ← Build Bundle(s) / APK(s) ← Build APK(s)` را بزن.
۴. فایل ساخته‌شده اینجاست: `app/build/outputs/apk/debug/app-debug.apk`
۵. فایل را برای گوشی بفرست و نصب کن (اگر خواست، «نصب از منبع ناشناس» را برای همان برنامه‌ی فایل‌منیجر فعال کن).

یا اگر گوشی با USB وصل است و «USB debugging» روشن است، فقط دکمه‌ی ▶ Run را بزن.

### با خط فرمان (اختیاری)
اگر Gradle نصب داری: `gradle assembleDebug` در پوشه‌ی پروژه.


## ساخت APK بدون نصب Android Studio (با GitHub، رایگان)

۱. در github.com حساب رایگان بساز و یک مخزن (Repository) جدید بساز.
۲. محتوای همین پوشه را در مخزن آپلود کن (Add file ← Upload files). اگر پوشه‌ی مخفی `.github` آپلود نشد، در GitHub گزینه‌ی `Add file ← Create new file` را بزن، نام فایل را `.github/workflows/build-apk.yml` بنویس و محتوای فایل `build-apk.yml` را که در این پروژه هست داخلش بچسبان.
۳. به تب **Actions** برو؛ ساخت خودکار شروع می‌شود (حدود ۵ دقیقه). اگر شروع نشد، روی «Build APK» و بعد «Run workflow» بزن.
۴. وقتی تیک سبز شد، روی همان اجرا کلیک کن و از پایین صفحه‌ی **Artifacts** فایل `planner-apk` را دانلود کن. داخل آن `app-debug.apk` است؛ آن را روی گوشی نصب کن.

## بعد از نصب
- اجازه‌ی **اعلان‌ها** را قبول کن (اندروید ۱۳ به بالا خودش می‌پرسد).
- در برنامه: `بیشتر ← یادآورها` دکمه‌ی «🔔 اجازه‌ی اعلان و آلارم» و «🔋 تنظیم باتری» را بزن و برای این برنامه **محدودیت باتری را بردار**. در گوشی‌های شیائومی، سامسونگ، هوآوی، اوپو و … این مرحله برای رسیدن به‌موقع اعلان‌ها مهم است.
- با «🔊 آزمایش اعلان» درستی کار را امتحان کن: برنامه را ببند؛ بعد از ۵ ثانیه باید اعلان بیاید.

## نکته‌ها
- اپ فقط در **صفحه‌ی اصلی برنامه** آلارم‌ها را از روی کارهای ۳۰ روز آینده هماهنگ می‌کند؛ هر بار کاری را اضافه، ویرایش یا انجام بدهی، آلارم‌ها خودکار به‌روز می‌شوند.
- داده‌ها فقط روی همین گوشی هستند. اگر برنامه را پاک کنی، داده‌ها هم پاک می‌شوند؛ پس گاهی از «تنظیمات ← دانلود پشتیبان» بگیر.
- فونت وزیرمتن هنگام اتصال به اینترنت از Google Fonts بارگیری می‌شود؛ بدون اینترنت از فونت خود گوشی استفاده می‌شود.
- شناسه‌ی برنامه `app.lifeplanner` است؛ اگر خواستی تغییرش بدهی، در `app/build.gradle.kts` (applicationId و namespace) و پوشه‌ی `java/app/lifeplanner` عوض کن.
- نسخه‌ی release برای انتشار در گوگل‌پلی نیاز به امضای شخصی (keystore) دارد؛ برای استفاده‌ی شخصی همین APK دیباگ کافی است.

## ساختار
- `app/src/main/assets/index.html` — خود برنامه‌ی پلنر (همان نسخه‌ی ۲).
- `MainActivity.java` — WebView، انتخاب فایل، دکمه‌ی برگشت، مجوزها.
- `Bridge.java` — پل جاوااسکریپت ⇄ اندروید (ذخیره‌ی فایل، آلارم‌ها).
- `Reminders.java`, `ReminderReceiver.java`, `BootReceiver.java` — آلارم‌ها و اعلان‌ها و تنظیم دوباره بعد از روشن شدن گوشی.
